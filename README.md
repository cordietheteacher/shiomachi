# The Constable of Shiomachi

A voiced story game set in a Japanese fishing town, from the arrival of the American ships in 1853 through the Meiji era. Play it in the browser at https://cordietheteacher.github.io/shiomachi/

Voices were generated with Qwen3-TTS VoiceDesign (open-source, Apache 2.0), takes chosen with the Chatterbox VoiceEncoder, and encoded with LAME (lameenc). All free tools.
